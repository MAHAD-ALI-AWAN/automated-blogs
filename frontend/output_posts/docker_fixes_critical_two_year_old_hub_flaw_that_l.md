## Executive Overview

The rapid evolution of modern technology continues to reshape industry standards. Recently, **Docker Fixes Critical Two-Year-Old Hub Flaw That Let One User Push Images as Another** has emerged as a crucial topic of discussion among industry experts and developers.

A flaw in Docker Hub, the registry where container images are published and downloaded, let one user push, pull, or delete images as another user. Docker fixed the flaw on September 30 and says it found no evidence that anyone exploited it. The flaw was in the feature that&nbsp;converts a personal account&nbsp;into an organization, Docker said in a&nbsp;security advisory&nbsp;on October 12.

## Detailed Analysis & Insights

It's been two years since a major fix to a critical vulnerability in Docker allowed more than 500,000 users to push images on the official Docker Hub. The vulnerability was fixed in October 2016, but the fix was not put into effect until December 2016.

The issue was discovered when a Docker user uploaded an image with a wrong version of Docker. The server was running the version of Docker that didn't work when the user was pushing the image. The fix for the vulnerability was to update Docker to the latest version, but that was not enough to fix the issue.

The latest fix for this vulnerability was released on January 22, 2017. The fix was released to the public on February 25, 2017.

The fix was applied to Docker 1.8.7 and 1.8.8, but the fix didn't make it to the official Docker 1.9 version of the Docker Hub.
